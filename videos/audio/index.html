Export & music sources

Save the JSON next to your song. From the repository root, run:

node videos/audio/mix.mjs --video /path/film.mp4 --song /path/song.mp3 --mix /path/komo-mix.json --out /path/film-with-music.mp4

The exporter keeps the picture untouched and combines music with all enabled sound cues. It requires FFmpeg and FFprobe. The demo button also downloads its original WAV so you can test the complete export.

Spotify’s API does not permit video synchronization. For a catalog, Jamendo Licensing offers video licenses; import the licensed download here. A catalog API integration needs a separate provider agreement.
